# Dynamics Wasted Time Tracker

Eine Browser-Erweiterung, die die Zeit misst, die bei Dynamics 365-Websites mit der Lade-Anzeige verschwendet wird.

## Features

✅ **Automatische Zeitmessung**: Misst automatisch die Zeit, wenn das `ShellProcessingDiv` Element auf Dynamics.com-Seiten sichtbar ist

✅ **Zwei Zeitzähler**:
- **Wasted Time Today**: Zeit verschwendet heute (wird täglich zurückgesetzt)
- **Wasted Time Total**: Gesamte Zeit verschwendet seit Installation

✅ **Sound-Benachrichtigungen**: Spielt einen benutzerdefinierten Sound ab, wenn die Lade-Anzeige sichtbar wird

✅ **Datenverwaltung**:
- Daten exportieren als JSON
- Daten importieren aus JSON-Datei
- Alle Daten zurücksetzen

✅ **Echtzeit-Abzeichen**: Zeigt die aktuelle Zeit als Abzeichen auf dem Icon an

## Verwendung

1. **Navigation zu Dynamics.com**: Navigiere zu einer beliebigen Website mit der Domain `*.dynamics.com`

2. **Automatische Zeitmessung**: Sobald die Lade-Anzeige (`ShellProcessingDiv`) sichtbar wird, startet die Zeitmessung automatisch

3. **Icon-Symbol anschauen**: Klicke auf das Erweiterungs-Icon in der Toolbar, um die aktuelle Zeit zu sehen

4. **Einstellungen öffnen**: Klicke auf den "⚙️ Settings" Button, um:
   - Sound-Benachrichtigungen zu aktivieren
   - Eine MP3-Datei als Benachrichtigungston auszuwählen
   - Daten zu exportieren/importieren
   - Alle Daten zurückzusetzen
